# Contributing to AROMI

First off, thank you for considering contributing to AROMI! It's people like you that make AROMI such a great tool for Anganwadi Centers.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) first. If it doesn't exist, feel free to open a new one!

## Fork & create a branch

If this is something you think you can fix, then fork AROMI and create a branch with a descriptive name.

## Code Review Process
The core team looks at Pull Requests on a regular basis. After feedback has been given we expect responses within two weeks. After that time we may close the pull request if it isn't showing any activity.

## Development Setup
Please refer to the README.md for local environment setup instructions.
